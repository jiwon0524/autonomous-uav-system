# Phase 2 — 디자인 시스템 작업 기록 (진행 중)

Aerospace Dark/Day의 의미 토큰과 기존 컴포넌트를 유지한다. 텍스트·경고는 색뿐 아니라 단어와 상태 아이콘을 함께 사용한다. 수신하지 않은 값은 기존 `—`/미수신으로 유지한다. Pretendard → Noto Sans KR → Malgun Gothic → Ubuntu → system-ui 순의 설치 폰트 폴백을 사용하며 폰트 파일은 포함하지 않는다. 기존 수치 컴포넌트의 tabular numerals를 유지한다.

표면 `--surface`: Dark #151B1F / Day #F8FAFB; 텍스트 `--text`: #E9EEF2 / #182C38; 보조 `--muted`: #A9B5BD / #536977; 강조 `--accent`: #61B7FF / #176591; 경고 #FDB84B / #885000; 위험 #FF5A57 / #AE2F2C. 공통 간격은 4/8/12/16/24/32px, 기본 모서리 4px. 표준 제어와 `:focus-visible`을 유지하고 새 화면 집중 버튼에도 텍스트와 pressed 상태를 제공한다.

표면 위 계산 대비: Dark 기본 14.88, 보조 8.30, 낮은 강조 5.94, 경고 10.04, 위험 5.67; Day 기본 13.77, 보조 5.49, 경고 6.28, 위험 6.19. Day 낮은 강조는 기존 4.36으로 4.5 미만이라 #5B7180(4.87:1)으로 조정했다. 이 값은 해당 단색 조합만 계산한 것이며 지도·투명 배경·비활성·모든 조합의 WCAG 적합성 검사는 아니다. 11–12px의 소형 텍스트, 입력·탭·모달·스크롤바의 일관성과 실제 배율은 추가 검증이 필요하다.

집중 보기는 내비게이션과 우측 패널을 임시 축소하면서 연결·안전·명령 잠금 상태줄을 유지하고, 일반 보기로 이전 상태를 복원한다. 네이티브 전체 화면은 별도 기능이다. 화면 전환과 창 크기 변경은 입력 미리보기를 초기화한다. 패널 자유 배치나 설정 저장은 구현하지 않았다.
