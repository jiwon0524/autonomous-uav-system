# Phase 6 로컬 패키지 및 Windows 후보 준비

## 공개 main 기반 정리 브랜치

공개 main을 부모로 하는 독립 스냅샷 브랜치를 준비하고 기존 main의 삭제 75개와 이름 변경으로 감지된 대시보드 파일 2개를 원본 그대로 복원했다. 원본 개발 이력은 가져오지 않는다. 공개 저장소에 이미 있던 파일과 이번에 새로 공개할 내용을 구분한다. Windows 수동 시험 워크플로는 Tauri 및 프런트엔드 경로를 명시하고 0.1.1 시험 설치기, SHA256 및 빌드 커밋을 업로드한다. 실제 네이티브 빌드·설치·업데이트와 데이터 보존은 NOT TESTED이며 별도 승인 전 원격 작업을 하지 않는다. 아래 구절은 과거 체크포인트다.

## 원격 push 보류 — 과거 로컬 커밋의 홈 경로

공개 `origin/main` 기준으로 이 브랜치에만 존재하는 Git 패치 이력에서 현재 사용자의 홈 디렉터리 원문이 발견됐다. `git log -p origin/main..HEAD`의 정확 문자열 대조에서 20회이며, 현재 지도 키 및 개인 키 마커는 같은 검사에서 0회다. 인계 문서의 현재 파일에 남아 있던 경로는 비식별화했지만 이전 커밋 객체는 그대로다. `origin/main`의 최신 로컬 참조는 공개 원격 main과 일치하는 것을 읽기 전용 API로 확인했다. 사용자 지시에 따라 이 이력을 그대로 공개하는 push는 보류하며, 기존 Git 이력은 변경하지 않는다. 이 검사만으로 모든 민감 정보 부재를 보장하지 않는다. 이력 보존과 공개 안전을 동시에 만족하는 별도 전달 방법은 사용자의 판단이 필요하다.

추가 메타데이터 검사에서 `origin/main..HEAD`의 작성자·커미터 주소 항목 174개 중 64개가 개인 이메일 서비스 도메인이었다. 주소 원문은 기록하지 않는다. 새 로컬 브랜치를 그대로 push하면 조상 커밋의 메타데이터도 공개되므로 이 역시 원격 보류 사유다. 기존 커밋을 덮어쓰거나 변경하지 않았다.

## 0.1.1 로컬 버전 정책 (진행 중)

사용자 지시에 따라 앱·Cargo·프런트엔드·Windows 시험 설치기·DEB의 내부 버전을 0.1.1로 일치시켰다. Preview 1의 0.1.0보다 높으므로 기존 NSIS 템플릿의 버전 비교에서 업데이트 경로를 선택하도록 준비한다. 공개 Preview 1 설정의 식별자 `org.firescene.gcs`와 현재 식별자, 일반 사용자 설치 정책이 같음을 읽기 전용으로 확인했다. 저장 경로를 변경하지 않는다. 제안 태그는 `v0.1.1-hardware-preview.2`이며 아직 태그 또는 Release를 생성하지 않았다. 실제 Preview 1 업데이트·사용자 데이터 보존은 Windows 시험 전 NOT TESTED다. 이전 0.1.0 검증 DEB와 결과는 이력으로 보존한다.

- 공개 [Preview 1](https://github.com/jiwon0524/autonomous-uav-system/releases/tag/v0.1.0-hardware-preview.1)은 실제 존재하며 Windows 설치 파일의 버전은 0.1.0이다. 현재 앱·NSIS·DEB 내부 버전도 0.1.0이므로 NSIS는 같은 버전 재설치 경로로 판단한다. `v0.1.0-hardware-preview.2`는 제안 태그일 뿐 생성하지 않았다. 업데이트 버전 및 공개 태그는 승인 후 확정하고, 실제 Windows에서 사용자 데이터 보존을 시험해야 한다.
- 로컬 검증용 DEB `dist/phase6-local-validation/FireScene-GCS-Phase6-remapped-amd64.deb`: 5,134,216 bytes; SHA256 `fb23e3c1bccf9b8389e8886874eb1049f1314964fea458cf3328223b8fbf9b42`. 앱/패키지 버전 0.1.0, 식별자 `org.firescene.gcs`. CLI 2.12.6, 소스 `2372bb6` 기준, 경로 재매핑·심볼 제거. 시스템에 설치하지 않았으며 배포 후보는 아니다.
- DEB의 메타데이터, 실행 파일·데스크톱 등록·아이콘과 런타임 의존성을 확인했다. 추출 실행의 읽기 IPC 성공 및 가상 IPC 8개 미등록 PASS. 지도 키·현재 로컬 홈 경로·QA 오류 주입 표식 원문은 검사 파일에서 발견되지 않았으며 실행 파일은 stripped다. 전체 개인정보·모든 민감 문자열 검사 완료를 뜻하지 않는다.
- 최초 비재매핑 DEB는 홈 경로와 심볼을 포함하여 사용 금지. 재매핑 빌드도 다른 민감 정보·서명·Windows 결과 확인 전 공개 금지. 미서명 빌드는 Windows에서 게시자 확인 또는 SmartScreen 경고가 발생할 수 있다. 보안 기능을 비활성화하지 않는다.
- Windows Actions는 앱·프런트엔드 경로를 명시하고 시험 아티팩트 이름을 `FireScene-GCS-Phase6-Test-x64-setup.exe`로 분리한다. 네이티브 빌드 실행 및 다운로드 URL은 아직 없다. 커스텀 템플릿 전체 컴파일, 실제 Welcome/설정/진행/완료/제거·한국어/영어·100/125/150% DPI·업데이트/데이터 보존·오류 및 취소는 Windows에서 확인해야 한다.
- 다음 단계는 사용자의 별도 승인 후 브랜치 push 및 수동 Windows Actions. 공개 태그·Release 생성은 Windows 후보 확인 이후 별도 승인 대상이다. 실제 KOA FC·물리 COM·텔레메트리·물리 키보드·격리 SITL은 NOT TESTED.
