# 비행 전 점검 (설계 중)

연결·HEARTBEAT·식별·ARM·센서·배터리·GPS·위치·통신 품질은 수신 가능한 정보에 한해 출처와 최신성을 표시한다. 조종기·수신기, 프로펠러·기체, 환경은 사용자의 현장 확인이 필요하다. 미수신·무효·오래됨을 자동 통과로 표시하지 않는다. 확인은 항목의 관찰이며 PX4 arming 검사나 실제 비행 허가가 아니다. 체크리스트 완료 여부와 무관하게 실제 비행 명령은 잠김이다. 안전 관리 화면에 참고용 수신 관찰과 사용자 체크 3개를 구현했다. 확인은 화면 이탈·세션/연결 상태 변경 시 초기화한다. 실시간 필드의 상태와 시간 초과 및 미래 시각을 검사한다. 체크 완료와 명령 활성화는 연결되어 있지 않다.
