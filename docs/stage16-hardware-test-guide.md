# Stage 16 하드웨어 읽기 전용 검증 가이드

첫 시험은 프로펠러를 모두 분리한 상태에서 읽기 전용 통신만 확인한다. 비행 명령 잠금을 해제하지 않는다. 모터 작동과 실제 비행은 별도의 안전 검증 이후에 진행한다.

1. 프로펠러 분리, 기체와 FC의 전원 및 USB 연결 상태를 확인한다. 기체를 안전하게 고정한다.
2. QGroundControl을 실행하여 USB 장치 인식과 PX4 상태를 확인한다. GPS와 배터리 정보가 실제 장치의 상태와 일치하는지 확인한다.
3. **직접 연결**: QGroundControl에서 직렬 포트를 해제하거나 종료한다. FireScene 시스템 설정에서 USB 포트와 baud를 선택하고 연결한다. HEARTBEAT와 GPS, 배터리 및 안전 경고를 확인하고 연결 해제 후 재연결한다. 데이터가 없으면 연결 성공으로 간주하지 않는다.
4. FireScene의 직렬 연결을 해제한다. **전달 연결**: QGroundControl이 직렬 포트를 소유하도록 연결하고 MAVLink forwarding을 127.0.0.1의 FireScene 수신 포트로 설정한다. FireScene에서 QGroundControl 전달 경로와 동일한 포트를 선택해 수신한다. 두 프로그램이 동일한 직렬 포트를 동시에 열지 않는다. Router를 쓰는 경우에도 직렬 소유자를 하나로 두고 같은 로컬 UDP 목적지를 설정한다.
5. HEARTBEAT와 GPS, 배터리 표시 및 안전 경고를 확인한다. 장치 분리 시 연결 손실 표시와 재연결 후 복구를 확인한다. 실제 수신 기록을 저장하고 별도로 재생하여 실시간 값과 구분되는지 확인한다.
6. 문제 발생 시 포트 접근 권한, 다른 프로그램의 포트 점유, UDP 포트 점유, baud와 전달 목적지를 확인한다. 앱의 입력 초기화는 실제 기체 정지나 위치 유지를 보장하지 않는다.
