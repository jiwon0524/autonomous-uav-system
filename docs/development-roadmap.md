# FireScene GCS 개발 로드맵

기준: Stage 15. FireScene은 QGroundControl의 기체 설정·보정·정비·기본 비행 시험을 대체하지 않는다. 실제 기체 제어는 별도 안전 설계와 검증 전까지 잠겨 있다.

1. **사용자 GUI 및 패키지 검증** — Ubuntu 설치·실행, 기존 9개 화면과 두 테마, 키보드 미리보기의 입력·포커스·최소화·연결 손실, QGC forwarding 및 화면 표시를 안전한 시험 데이터로 확인한다. Windows 빌드와 실행도 별도 검증한다.
2. **실제 하드웨어 연결 검증** — KOA FC·PX4·M10 GPS·무선 텔레메트리 및 Pi 연결을 별도 안전 절차에 따라 확인한다. QGC 제어 권한과 FC failsafe, FireScene의 읽기 전용 감시를 구분한다. 비행 시험은 별도 결정한다.
3. **Companion·카메라·매핑 통합** — 팀과 메시지 버전, 시계·좌표·프레임·보정 계약을 합의하고 실제 장비와 대역폭·지연·자원을 측정한다. Depth 원본, 카메라 자세·경로, 점군 파일/증분 및 지도 정합은 아직 미완료다.
4. **보안과 배포** — Companion·영상·점군 인증·암호화·재생 방지, 신뢰 경계와 자원 제한을 설계·검증한다. QGC 및 Qt의 실제 재배포 조건은 번들 결정 전 별도 검토한다.
5. **후속 실제 제어 안전 설계** — 제어권 중재·상호 배타 모드·독립 failsafe·손실 처리·사람의 개입·하드웨어 검증을 별도로 설계한다. Stage 15 입력 미리보기는 기체 정지나 제어 안전성을 보장하지 않는다.
6. **자율비행은 마지막 단계** — A*, DQN, 장애물 회피 및 자율 실행은 위 검증과 별도 승인·안전성 검증 전까지 보류한다. 카메라 처리·객체 탐지·Depth·SLAM은 팀원 모듈과 계약을 통해 연동하며 중복 개발하지 않는다.
