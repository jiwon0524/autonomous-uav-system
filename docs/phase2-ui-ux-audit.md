기존 CSS에 V1/V2 테마 중복과 1250/1050/950px 후속 재정의가 존재했다. 사용하지 않는 V1 테마 토큰은 제거했으나 전체 CSS 정리 및 모든 모달·빈 상태의 감사는 미완료다. 설정, 데이터 모델, 안전 판단 및 통신을 변경하지 않았다.

910×512 Linux 가상 창에서 상태줄은 보이지만 지도와 내비게이션이 좁고 내부 스크롤이 여러 개 생긴다. 사용자 영향은 높으며 집중 보기와 별도로 반응형 배치를 더 개선해야 한다. Windows 실제 150% 검증은 미완료다.
