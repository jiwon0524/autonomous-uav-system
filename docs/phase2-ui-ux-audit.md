기존 CSS에 V1/V2 테마 중복과 1250/1050/950px 후속 재정의가 존재했다. 사용하지 않는 V1 테마 토큰은 제거했으나 전체 CSS 정리 및 모든 모달·빈 상태의 감사는 미완료다. 설정, 데이터 모델, 안전 판단 및 통신을 변경하지 않았다.

910×512 Linux 가상 창에서 상태줄은 보이지만 지도와 내비게이션이 좁고 내부 스크롤이 여러 개 생긴다. 사용자 영향은 높으며 집중 보기와 별도로 반응형 배치를 더 개선해야 한다. Windows 실제 150% 검증은 미완료다.

## 2026-11-26 반응형 후속

이전 910×512 캡처에서 160px 메뉴와 230px 상황 패널이 지도 폭을 차지해 핵심 지도 면적이 좁았다. 1150px 이하에서는 62px 아이콘 메뉴와 닫힌 상황 패널을 기본으로 사용하고 각각 버튼으로 펼친다. 910×512/1093×614 실제 Tauri 가상 화면에서 지도의 바깥 폭이 각각 창 너비−110px 이상인 것과 메뉴·상황 패널 열기/닫기를 검사했다. 캡처상 910×512에서 메뉴 9개 아이콘이 보이고 지도 폭은 개선됐지만, 툴바·검색·지도 메타정보 때문에 실제 지도 높이는 여전히 제한적이다. 메뉴 콘텐츠 전체와 팝업의 넘침은 별도 검사가 필요하다. 작은 화면의 우측 패널은 지도를 덮는 비모달 패널이며 Escape나 닫기 버튼으로 닫는다.

시스템 설정은 기체 연결·전달 수신·외부 장치·지도·화면의 실제 항목으로 이동하는 분류를 추가했다. 새로운 무선 통신 설정이나 구현되지 않은 저장 기능은 표시하지 않는다. 3D는 연결·상세 상태를 펼침 영역으로 옮겨 점군에 더 많은 공간을 할당했다. 카메라·비행 제어·임무·자율비행·안전·기록의 전면 재설계는 이번 후속 범위에서 완료되지 않았다.

안전 배너의 기존 접근 가능한 이름이 심각도와 메시지를 덮어쓰는 문제가 있어 이름에 현재 상태와 내용을 포함했다. 활성 경고는 판단 기준 변경 없이 심각도순으로 표시한다.

## 최종 재개: 메뉴별 적용 및 잔여 사항

| 메뉴 | 적용 | 잔여 사항 |
|---|---|---|
| 종합 관제 | 짧은 창의 지도 상태를 펼침 영역으로 이동하고 제목·하단의 중복 여백을 줄임 | 910×512에서 지도 캔버스는 150px이고 현장 정보 펼침 영역은 지도를 일시적으로 가림 |
| 비행 제어 | 미수신 자세의 빈 높이 축소, 상세 그래프 선택 표시 | 실제 기체 자세와 물리 키 미검증 |
| 임무 계획 | 작은 창 지도 정보 접기, 선택 상태와 삭제 버튼 강조 | 위치 확정·수정·삭제의 모든 오류 흐름 및 실제 사용자 파일 미검증 |
| 자율비행 | 현재 임무·미구현 상태·명령 잠금 및 임무 계획 진입 표시 | 경로·진행 데이터는 구현하지 않음 |
| 3D 매핑 | 짧은 창 제목·도구 여백 축소, 기존 집중 보기 유지 | 일반 작은 창에서 점군 화면이 여전히 일부만 보이며 집중 보기/스크롤이 필요 |
| 카메라 | 짧은 창과 집중 보기에서 영상 크기를 높이와 실제 종횡비에 맞춤 | 실제 영상 장비·0개 탐지 수신 상태는 별도 시험 필요 |
| 안전 관리 | 기존 심각도 순서와 확인/종료 표시 유지, 경고 시간에 의미 있는 시간 요소 적용 | 실제 FC 연결 손실·전 경고 조합 미검증 |
| 비행 기록 | 재생 탐색 막대를 별도 행에 배치하고 시간 숫자 고정폭·삭제 강조 | 대량·손상 기록의 모든 시각 상태 미검증 |
| 시스템 설정 | 프로그램 정보와 비행 기록 이동을 기존 목적별 바로가기에 추가 | 장치 연결의 실제 Windows COM 동작과 사용성 평가 미실행 |

P2: 작은 창의 3D 일반 보기에는 스크롤이 남고, 일부 보조 글씨와 내부 패널·검색 결과의 긴 내용은 추가 가독성 검토가 필요하다. 팝업 전체의 물리 키 및 접근성 전수 시험은 미완료다. 현재 자동화와 화면 표본에서 확인된 P0/P1은 없지만 전수 검증의 부재가 결함 부재를 증명하지 않는다. 실제 Windows 설치·DPI, KOA FC, 카메라·Depth·3D 장비 시험은 외부 환경 항목이다.
