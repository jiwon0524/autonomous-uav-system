# FireScene Design V2 — 실험 디자인 시스템

이 문서는 `design-v2-experimental`의 Stage 20-2 기준이며 `design-v1.0`을 대체하는 승인된 디자인이 아니다. 연구의 Aerospace Mission Control 정보 계층을 적용하고 Urban Response의 기존 통합 검색을 보존한다. Globe와 전용 지도 스타일은 후속 단계다.

## 구성

- 상단: 선택 임무, 연결 출처, 비행 모드·ARM·GPS·배터리, 안전 감시, 기록 상태와 명령 잠금. 값이 없으면 미연결/확인 불가를 유지한다.
- 왼쪽: 9개 기존 메뉴와 명시적인 접기·펼치기. 접근성 이름은 접힌 상태에서도 유지한다.
- 중앙: OpenLayers 지도와 기존 VWorld 검색/건물 선택. 하단에 상대 고도·지상 속도·기체 방향과 입력 미리보기 진입. 실제 수신 데이터만 사용한다.
- 오른쪽: 현장·기체·안전·조종 상황 패널. 그래프는 기체 패널의 상세 항목을 펼칠 때 표시한다. 조종 미리보기에서 다른 탭 또는 메뉴로 이동하면 컴포넌트가 종료된다. 기존 비행 모드 최신성, 창 포커스, 시간 초과와 실제 명령 잠금을 유지한다.
- 짧은 창에서는 내부 스크롤로 기능 접근을 보존한다. 지도 타일은 왜곡 필터 없이 원본과 출처를 유지한다.

## 색상과 서체

Dark 기본 `#0B0F12`, 패널 `#151B1F`, 텍스트 `#E9EEF2`, 보조 `#8B99A3` 계열, 선택 `#61B7FF`, 주의 `#FDB84B`, 위험 `#FF5A57`. 보조 텍스트에는 가독성을 위해 더 밝은 `#A9B5BD`를 사용한다. Day는 밝은 배경·짙은 텍스트와 파란 선택색의 별도 토큰을 사용한다. Pretendard/Noto Sans KR이 시스템에 있으면 사용하고 없으면 시스템 sans-serif로 대체한다. 별도 폰트나 라이브러리를 추가하지 않았으며 숫자에는 tabular numerals를 적용한다.

빨강은 위험·오류에, 주황은 주의·기록 중에 사용한다. 상태를 색상만으로 전달하지 않고 텍스트를 함께 표시한다. 이 토큰은 향후 실제 운영자와 접근성 검증을 거쳐야 한다.
