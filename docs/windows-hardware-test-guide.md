# Windows 11 설치 및 KOA FC 읽기 전용 확인

이 안내는 Windows x64 설치 프로그램이 **빌드되고 검증된 뒤** 사용한다. 현재 설치 파일과 KOA FC 호환성은 확인되지 않았다. 처음에는 프로펠러를 모두 분리하고 기체를 고정한다. 모터 작동이나 비행을 시도하지 않는다.

1. 프로젝트의 승인된 GitHub Releases에서 `FireScene-GCS_0.1.0_x64-setup.exe`와 `SHA256SUMS.txt`를 받는다. 현재는 공개 Release가 없을 수 있다. 확인 전 Actions 테스트 Artifact를 정식 배포본으로 취급하지 않는다. 서명되지 않은 시험 빌드는 Windows가 게시자를 확인할 수 없다고 표시할 수 있다. 파일의 출처와 제공받은 SHA256을 확인하고, 확실하지 않으면 실행하지 말고 제공자에게 확인한다.
2. 설치 파일을 실행하고 마법사를 따른다. 현재 사용자 계정에 설치되도록 설정했으며 완료 화면의 바탕화면 바로가기 선택과 시작 메뉴 `FireScene GCS`를 사용할 수 있다. 설치 관리자·바로가기·제거 동작은 실제 Windows에서 아직 확인해야 한다. 기존 WebView2 Runtime이 있으면 재사용하고 없으면 인터넷에서 WebView2 설치 프로그램을 내려받도록 설정했다. 이때 인터넷 연결이 필요하다. 설치 과정에서 시스템 권한 요청이 발생할 수 있다.
3. FireScene GCS를 실행한다. 지도는 시스템 설정에서 본인의 VWorld 키와 인터넷이 필요하다. 키가 없거나 지도가 동작하지 않아도 기체 연결을 시도할 수 있다. 다른 사람에게 받은 설치 프로그램이나 화면에 키를 공유하지 않는다.
4. 기체 전원과 USB 데이터 케이블을 확인하고 KOA FC를 노트북에 연결한다. Windows 장치 관리자에서 **포트(COM 및 LPT)**에 해당 장치가 나타나는지 확인한다. 없다면 케이블, 전원 및 실제 장치 제조사의 드라이버 요구사항을 확인한다. 임의 드라이버를 설치하지 않는다.
5. FireScene의 **시스템 설정 → 직렬 장치**에서 감지된 COM 포트를 선택한다. 장치가 목록에 나타나는 것은 USB 장치가 감지됐다는 뜻이다. 통신 속도는 FC의 MAVLink 설정을 확인해 선택한다. 다른 포트 프로그램이나 QGroundControl이 같은 COM 포트를 열고 있으면 해제한 뒤 **수동 연결**을 누른다.
6. `HEARTBEAT 대기`는 아직 연결 성공이 아니다. 유효한 PX4 HEARTBEAT가 들어오면 기체 상태로 표시된다. 이 앱은 현재 PX4로 식별되는 유효 HEARTBEAT를 요구한다. KOA FC의 펌웨어·설정·MAVLink 호환성은 미확인이다. GPS·배터리와 데이터 수신 시각을 실제 장치 정보와 비교한다. 데이터가 없거나 오래된 필드는 확인 불가로 취급한다.
7. 연결 실패 시 선택한 COM 포트, 속도, 케이블, 장치 권한, 드라이버 및 다른 프로그램의 포트 점유를 확인한다. 연결 해제 후 USB를 분리·재연결하고 다시 시도한다. 자동 연결은 유일한 USB 일련번호를 가진 장치를 명시적으로 허용할 때만 사용한다. 포트 발견만으로 비행 준비를 판단하지 않는다.
8. 읽기 전용 안전 경고와 기록 저장·재생을 확인한다. 연결과 표시만 확인하며 ARM, 이륙, 착륙, 키보드 비행 제어 및 자율비행을 시도하지 않는다. QGroundControl은 별도 선택 도구이며 직접 연결과 같은 포트를 동시에 사용할 수 없다.

임무와 기록은 현재 사용자 앱 데이터 디렉터리, 지도 키는 앱 설정 디렉터리에 저장한다. Windows의 정확한 경로와 업데이트/제거 시 보존은 실제 설치 후 확인해야 한다. 프로그램 제거 전에 필요한 임무와 기록은 백업한다. 비행 기록 JSONL은 앱의 기록 화면에서 내보낼 수 있다.
# Windows KOA FC 비교 시험

프로펠러를 제거하고 동일한 KOA FC와 USB 데이터 케이블을 사용한다. 두 프로그램이 동일 COM 포트를 동시에 점유하지 않도록 한다. 펌웨어 설치나 설정 변경은 이 시험에 포함하지 않는다.

1. FireScene을 완전히 종료한다. 장치 관리자에서 COM 포트와 장치 상태를 기록한다.
2. QGroundControl을 실행하고 USB로 연결해 PX4 인식 여부, COM 포트, 실제 자세 값의 변화 여부를 기록한다. 연결 성공을 미리 가정하지 않는다.
3. QGroundControl을 완전히 종료한다. FireScene에서 자동 연결을 끄고 같은 포트를 수동 선택한다. 연결 상태와 진단 정보를 복사해 전달한다.
4. QGC가 성공하고 FireScene이 실패하면 복사한 바이트·프레임·HEARTBEAT 수와 포트 열기 결과를 비교한다. QGC도 실패하면 케이블, 장치 관리자, 전원과 펌웨어/부트로더 상태를 확인하고 결과를 기록한다. 펌웨어 변경 전 별도 확인이 필요하다.

현재 변경은 Windows 네이티브 및 실제 FC에서 검증되지 않았고 새로운 설치 파일은 아직 없다. 합성 데이터의 성공을 하드웨어 성공으로 해석하지 않는다.
