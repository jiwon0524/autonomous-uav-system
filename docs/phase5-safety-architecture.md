# Phase 5 안전 아키텍처 (진행 중)

기준 `a347168`; Phase 4 미완료 검증은 `phase6-pending-validation.md`. 실제 통신은 기존 읽기 전용 수신기다. 제어 전송 경로와 ARM·이륙·착륙·모터·waypoint·모드 변경 경로를 추가하지 않는다.

연결 관리자 → 선택된 기체와 세션 → 필드별 검증/TTL → 관찰 안전 모니터 → 읽기 전용 화면·기록. 별도 개발 전용 가상 권한·입력·상태 실행기는 실제 연결 관리자나 MAVLink transport에 접근할 수 없는 구조로 설계한다. 재생은 표시 전용이며 가상 입력·실시간 안전 판단의 소스가 아니다. PX4가 실행하는 failsafe와 FireScene의 관찰 경고를 혼동하지 않는다.

현재 안전 monitor의 battery/GPS/센서/자세가 missing, INVALID, STALE일 때 NORMAL이 되지 않는 단위 시험을 보완했다. 연결·세션 경계 전체와 GUI는 아직 추가 시험이 필요하다. 개발용 메모리 모델은 별도 Rust 모듈로 존재하지만 IPC에 노출되지 않는다. 안전 상태·연결·재생과 권한을 연결하는 관리자, 기록·GUI 및 종단 간 격리 검증은 미구현이다.

## 가상·연결 상호 배제 중간 단계

개발 simulation 빌드의 연결 관리자는 직렬 및 UDP 연결 시작과 가상 세션 획득을 공통 mutex로 직렬화한다. 가상 획득은 OFFLINE이며 실행 중 연결 worker가 없을 때만 허용하고 활성 가상 세션 중 새 연결을 거부한다. 모델은 연결 관리자를 참조하지 않는다. 동시 요청 10회 및 각 경로 단위 시험이 통과했다. 세션별 토큰이 맞지 않는 오래된 해제는 거부한다. 아직 가상 획득/해제는 IPC에 연결되지 않았고 재생 차단·프로세스 수명·watchdog 종단 간 검증을 제공하지 않는다.

## 2026-11-26 통합 현황

위 중간 설계 설명보다 최신: 개발 simulation 전용 IPC·GUI는 연결 및 재생 권한과 상호 배제된다. 500ms 입력 임대를 50ms 주기 백엔드 감시로 검사한다. 이벤트는 유한 큐에 비차단 전달하고 별도 작업자가 기록한다. 큐 포화나 작업자 오류는 실패로 유지하며 신규 시작을 거부한다. 기록 정지 중 권한 회수 단위 시험과 웹뷰 비응답 실제 GUI 시험은 통과했으나 생산 IPC 및 외부 환경 검증은 아직 미완료다.
