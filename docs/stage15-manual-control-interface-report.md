# Stage 15 키보드 조종 입력 미리보기 보고

기준 `dev/firescene-gcs`, Stage 14 `188bbe4`, `design-v1.0`, `alpha-v0.1.0`. 이 문서를 포함한 커밋은 `git log -1`로 확인한다. 원격 push와 실제 기체 연결·제어·비행 시험은 하지 않았다.

## 구현 범위

종합 관제와 비행 제어 화면에 모드 진입 버튼을 추가했다. 일반 상태는 MONITOR이며 매뉴얼·입력 및 속도 UI는 숨긴다. 사용자 선택 시 MANUAL PREVIEW만 실행하고 접이식 매뉴얼·입력 키 강조·이동/회전 미리보기 단계·연결·비행 모드·안전 감시·잠금을 표시한다. 실제 MANUAL CONTROL 및 AUTONOMOUS는 이름만 예약된 배타적 상태로, 실행·전환 경로가 없다. 실제 제어 기능에 대한 안전 구조가 완성됐다는 뜻은 아니다. QGroundControl 제어 상태나 제어권 이전은 확인하지 않는다.

독립 키 맵: W/S 전진·후진, A/D 좌/우 평행 이동, ↑/↓ 상승·하강, ←/→ 좌/우 회전. Space는 UI 입력을 지우고 누르고 있던 키는 물리적으로 놓기 전 다시 활성화하지 않는다. Escape는 미리보기를 종료한다. 반대 방향은 합산 시 0이며 여러 축을 동시에 표시한다. 속도는 1–5 UI 단계일 뿐 단위·기체 속도 설정이나 전송 기능이 아니다. 입력 상태 초기화는 모터 정지, DISARM, 기체 정지 또는 위치 유지를 보장하지 않는다.

## 입력 및 안전 경계

진입은 연결된 수신 상태, 안전 상태 조회 가능, LIVE 비행 모드 및 해당 시각 3초 미만, 보이는 창과 포커스를 요구한다. 따라서 오프라인에선 미리보기에 진입할 수 없다. 키 해제는 해당 입력을 지우고, Space는 전체 입력을 지운다. Escape, 포커스 상실, 숨김/최소화, 문자 입력란 포커스, 화면 이탈·컴포넌트 종료, 연결/최신성 상실 또는 OFF는 상태를 지우고 종료한다. 누른 키 하나가 2초 동안 해제되지 않으면 모드를 종료한다. 연결/최신성 및 시간 초과는 100ms 간격의 UI 타이머로 검사하므로 프로세스 중단·스케줄 지연 중 즉시 실행을 보장하지 않는다. 복구 후 자동 재개하지 않는다.

앱 창의 활성 미리보기 중 지정 키만 처리하고 시스템 전역 후킹은 없다. Ctrl/Meta/Alt/Shift 조합은 가로채지 않는다. 입력란 포커스 시 미리보기를 종료해 기존 문자 입력을 보존한다. 실제 GUI의 OS별 최소화·포커스·단축키 동작은 미검증이다. 새 코드는 Tauri invoke, 네트워크 또는 MAVLink 송신 경로가 없고 기존 읽기 전용 QGC·안전 감시를 바꾸지 않는다.

## 검증 및 배포

- 프론트엔드 9개 테스트 파일 통과. 상태 기계에서 진입 거부/허용, 동시 입력, 반대 방향, 키 해제, Space 후 재입력 차단, 포커스/화면 이탈 등에 쓰이는 종료 전이, 시간 초과·최신성 상실·자동 재개 방지 및 미래 모드 충돌 거부를 검증했다. DOM 키 이벤트·접이식 UI·창 포커스/최소화 및 실제 데이터 연동은 자동 GUI 시험을 수행하지 않았다.
- TypeScript 및 Vite 빌드 통과. Rust 기본 47개, simulation 48개와 각 Tauri 권한 구성 검사 1개 통과, 합성 성능 시험 각 1개 제외. 루프백 검사는 승인된 환경에서 실행했다. 기존 안전 감시 회귀를 포함하며 실제 GUI 동시 동작은 미검증이다.
- Ubuntu 24.04 amd64 Tauri 릴리스 및 DEB 성공. `src-tauri/target/release/bundle/deb/FireScene GCS_0.1.0_amd64.deb`: **5,709,346 bytes**, Stage 14의 5,708,628 bytes 대비 **718 bytes 증가**. 실행 파일 18,698,616 bytes, frontend/dist 698,019 bytes. 배포 목록에서 개발 테스트 파일은 발견되지 않았다. Vite 메인 청크 500 kB 경고는 남는다.

## 남은 검증

Ubuntu 그래픽 세션에서 개발용 simulation 또는 안전한 시험 데이터로 진입 조건, 키 동시/반대 입력, Space·Escape, 매뉴얼, 포커스·최소화·텍스트 입력·메뉴 이동, 시간 초과 및 연결 손실을 확인한다. QGC 전달 경로의 실제 GUI, Windows, 실기체·하드웨어·안전성 검증은 PENDING이다. 실제 제어 기능은 별도의 설계·검증 단계까지 보류한다.
