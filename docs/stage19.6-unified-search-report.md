# Stage 19.6 통합 위치 검색

기준: `dev/firescene-gcs`의 `7ba22d5`. 미추적 Stage 0 보고서를 보존했다.

## 기존 방식과 변경

기존에는 사용자가 도로명/지번/장소 유형을 선택했고, 검색 API 2.0에 `type=road` 또는 `type=parcel`을 전달했다. 검색 결과를 선택하면 임무 현장 선택도 변경되는 문제가 있었다. 이제 입력창 하나에서 세 유형을 조회하고 후보 선택은 지도 이동과 마커만 수행한다. 건물 윤곽과 임무 현장은 지도에서 별도로 선택한다. 저장된 임무는 검색으로 수정하지 않는다.

`https://api.vworld.kr/req/search`, search 2.0, EPSG:4326, JSON, 페이지 1, 유형별 최대 10건을 사용한다. 도로명/지번은 `type=ADDRESS`와 `category=ROAD`/`PARCEL`, 장소는 `type=PLACE`다. title, address의 road/parcel/bldnm, point 등 제공된 필드만 표시한다. 원래 검색어로 세 요청을 한 번씩 수행하고 첫 결과가 정확하지 않으면 제한된 대체 장소 검색을 최대 한 번 수행한다. 검색 결과는 첫 페이지만 제공하며 전체 검색 결과를 보장하지 않는다. 호출 한도의 실제 수치는 확인하지 못했다. 반복 제출은 진행 중 차단하고 1초 간격을 두며 서버의 제한/인증 오류를 표시한다. 취소 및 입력 변경 시 늦은 응답은 무시하지만 이미 전송된 HTTP 요청을 중단하지는 않는다. 각 요청 제한시간은 10초다.

공식 [VWorld 검색 API 2.0 레퍼런스](https://www.vworld.kr/dev/v4dv_search2_s001.do)는 확인 시 시간 초과로 열리지 않았다. VWorld의 [공식 검색 예제](https://github.com/V-world/V-world_API_sample/blob/master/%5B%EA%B2%80%EC%83%89API%5D%20%EB%A7%88%EC%BB%A4%20%EB%8B%AB%EA%B8%B0%20%EC%9D%B4%EB%B2%A4%ED%8A%B8.html)는 PLACE와 반환 필드를 확인할 수 있었다. 주소 매개변수는 실제 API의 ROAD/PARCEL 응답으로 검증했다. 공식 문서의 전체 제한과 오류 코드 목록은 미확인이다.

정렬은 원문 정확 일치, 공백 제거 후 일치, 부분 일치, 그 외 유사 결과, 대체 검색 후보 순이다. 지도 중심에 따른 거리 필터는 적용하지 않는다. 중복은 같은 좌표와 같은 이름 또는 주소가 있을 때만 제거하므로 서로 다른 위치의 동명 장소는 유지하지만, 좌표가 약간 다른 동일 장소는 중복으로 남을 수 있다. 공백을 정리하고, 끝의 `대`를 `대학교`로 확장하거나 `대학고`를 `대학교`로 바꾸는 제한된 대체 검색을 사용한다. 이는 일반 맞춤법 교정기가 아니며 대체 및 유사 결과는 후보로 표시한다.

## 실제 API 확인 (2026-11-25)

기존 로컬 키로 첫 페이지를 직접 요청했다. 아래 숫자는 도로명/지번/장소 **각 원시 응답 건수**이며, 중복 제거 후 화면 건수나 검색 정확도의 증거는 아니다. 각 요청은 응답을 받았고 `OK` 또는 `NOT_FOUND`였다. 표시된 정확한 장소 여부는 첫 두 응답만 확인한 경우 한정이다.

원시 응답의 같은 주소 항목에 서로 다른 좌표가 있을 수 있어 일괄 삭제하지 않는다. 화면 정렬과 중복 제거는 합성 데이터 단위 테스트로 검증했으며 위 실제 결과의 화면 표시 및 정확한 순위는 GUI에서 확인해야 한다.

## 검증 및 남은 확인

프런트엔드 테스트 13개 파일(검색 정규화, 중복, 정렬, 응답 순서 포함), TypeScript 검사 및 프로덕션 프런트엔드 빌드, Tauri 권한 Rust 통합 테스트 통과. 기존 지도 기하와 임무 테스트도 통과했다. 네트워크 시험은 샌드박스 DNS 거부 후 권한을 받아 실행했다. 지도/임무의 실제 GUI 회귀, API 오류별 실제 응답, 대체 검색 종단 간 검증은 미실행이다. X 서버 접근이 불가능해 GUI 조작을 하지 못했다.

기존 `WebProcess didn't exit as expected after the UI process connection was closed` 메시지는 이번에 재현하거나 원인을 확인하지 못했다. 검색과의 관련성은 확인되지 않아 별도 보류한다. 새 DEB는 만들지 않았다.

변경 파일: `frontend/src/MapView.tsx`, `frontend/src/locationSearch.ts`, `frontend/tests/location-search.test.mjs`, `src-tauri/src/map.rs`, 이 보고서. 로컬 커밋은 이 보고서를 포함하는 커밋으로 `git log -1`에서 확인한다.

사용자 확인: 저장소 루트에서 `cargo tauri dev` 실행 후 임무 계획에서 기존 로컬 키로 위 검색어를 확인한다. 결과 선택 후 지도 이동과 기존 임무 현장이 유지되는지, 별도 건물 클릭·반경 변경·임무 저장/재시작 복구를 확인한다. 비행 명령 잠금은 유지한다.
