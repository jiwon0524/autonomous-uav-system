# Phase 6 Windows 설치기 — 진행 중

Tauri 번들러 2.10.6의 로컬 NSIS 템플릿을 `src-tauri/installer/firescene.nsi`로 가져와 Welcome을 nsDialogs 기반 FireScene 페이지로 교체했다. 기체 도면이 있는 자체 사이드바와 브랜드 문구를 사용한다. 이후 기존 버전 탐지, 디렉터리, 시작 메뉴, 실제 설치 진행, 완료 후 실행·바탕화면 바로가기, 제거 및 선택적 데이터 삭제 로직은 원본에서 유지했다. 한국어와 영어 Welcome 문구를 제공한다. 기존 WebView2 정책과 앱 식별자도 바꾸지 않았다.

이는 아직 **Windows에서 컴파일하거나 실행하지 않은 구현**이다. 페이지 크기·배율·번역·비트맵과 업데이트 및 제거 기능의 실제 동작은 NOT TESTED다. 설정·진행·완료·제거 페이지의 전용 전체 디자인은 미완료이며 기본 Tauri/MUI 흐름이다. 이 템플릿은 번들러 버전에 종속되므로 CLI 업데이트 시 원본과 다시 대조해야 한다. 미검증 템플릿으로 배포 후보를 생성하지 않는다. [Tauri 공식 문서](https://v2.tauri.app/distribute/windows-installer/)는 사용자 지정 템플릿을 지원하며 기능 유지를 위해 원본 템플릿 기반으로 작업했다.

## 후속 페이지 적용 및 로컬 검증

기존 MUI 페이지와 동작을 유지하면서 공통 어두운 헤더/완료 배경, FireScene 푸터, 설치 위치·시작 메뉴·진행·제거 제목과 한국어/영어 설명, 버전·읽기 전용·명령 잠금 완료 안내를 추가했다. 네이티브 경로·진행·삭제 선택 컨트롤 및 기존 업데이트/오류 로직을 교체하지 않았다. 바탕화면 바로가기는 기존 완료 페이지의 선택 항목이고 시작 메뉴는 별도 페이지다. WebView2는 필요 시 기존 부트스트래퍼가 처리한다. 사용자 데이터 삭제는 기존 제거 확인 페이지에서 선택 사항이다. 이전 설치 제거를 선택할 때에도 사용자 선택을 확인해야 하며 실제 업데이트 보존은 Windows에서 별도 시험해야 한다.

기존 Welcome의 `${LANG_KOREAN}`은 언어 파일이 삽입되기 전에 참조되어 NSIS 3.09에서 경고가 발생했다. 언어 ID 1042를 사용해 수정했다. `scripts/check-phase6-installer.py`는 설정·페이지·언어 문자열을 검사하고, 실제 Welcome 코드 및 각 MUI 페이지 선언을 이용한 독립 하네스를 `makensis -WX`로 컴파일했다. 경고 없이 PASS. 이는 Tauri 전체 템플릿 렌더링·플러그인·Windows 설치 시험이 아니다. 템플릿은 CLI 2.12.6이 사용하는 bundler 2.10.6 원본을 기준으로 한다.

`docs/phase6-concepts/installer-pages/`의 다섯 PNG는 실제 코드 구조를 설명하는 **목업**이며 Windows 렌더링이 아니다. 기본 MUI 설치 위치·진행·제거 페이지는 운영체제 네이티브 컨트롤과 밝은 본문을 유지한다. 전체 페이지가 Welcome처럼 짙은 배경·드론 도면으로 재설계된 것은 아니다. 특히 DPI·한글 잘림·고대비·버튼·오류·취소, Preview 1 업데이트 및 WebView2 실행은 Windows NOT TESTED다. 배포 후보로 판정하지 않는다.
