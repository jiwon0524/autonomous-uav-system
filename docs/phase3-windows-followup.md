# Phase 3 Windows 및 KOA FC 후속 시험

안정 후보는 OpenLayers/VWorld 기본 빌드다. 개발 전용 Global은 Windows WebView2에서 아직 검증되지 않았으며 안정 설치 파일에 포함되지 않는다. 기존 Preview와 하드웨어 진단 설치 파일은 보존한다.

## 설치·화면

1. 기존 사용자 임무와 설정을 백업하고 FireScene을 종료한다. 동일 앱 버전의 NSIS 재설치 안내와 데이터 보존을 확인한다.
2. Windows 디스플레이 배율 및 DPI, 창 크기와 Dark/Day를 기록한다. 지도 확대·축소와 위성 전환, 임무 저장·재시작 복원을 확인한다.
3. 실험 Global은 개발자가 Windows 네이티브 개발 환경에서 `frontend`의 `npm ci` 후 `src-tauri`에서 `cargo tauri dev --features simulation`으로 실행하는 개발 전용 구성이다. 이 구성은 개발 서버와 도구가 필요하고 친구에게 전달할 독립 실행 설치 파일로 검증되지 않았다. 실제 하드웨어 시험 시 simulation 대신 실제 연결을 명확히 선택한다. 생산 빌드와 혼동하지 않는다.
4. WebView2에서 평면·Globe·Tactical 복귀, 지도 표시·오류·리소스 해제와 GPU 가속 상태를 기록한다. 개발 빌드의 외부 지도 사용 조건과 출처 표시를 확인한다.

## KOA FC

프로펠러를 제거하고 동일 FC·USB 데이터 케이블을 사용한다. 장치 관리자에서 COM 포트를 확인하고 FireScene에서 자동 연결 또는 수동 연결 결과와 진단 복사를 기록한다. 포트 열기/설정, OS 코드, 수신 바이트, 유효 프레임, HEARTBEAT와 거부 사유를 전달한다. 현재 열기 및 직렬 설정 성공은 하나의 항목으로 표시된다. 기체 자세·위치가 실제로 바뀌는지 확인하고 케이블 분리·복구 후 연결 상태 및 기록을 확인한다. 읽기 전용 잠금을 유지하고 설정 변경·펌웨어 재설치는 하지 않는다.

QGroundControl 비교 시 FireScene을 완전히 종료한 뒤 같은 FC·케이블로 QGC의 펌웨어 인식과 자세 데이터, 포트를 기록한다. QGC를 완전히 종료하고 FireScene을 다시 연결한다. 같은 COM 포트를 동시에 열지 않는다. 연결 성공 여부는 실측 전 가정하지 않는다. 자세한 안내: `windows-hardware-test-guide.md`.

## Prior 3D 인증 및 호스팅

현재 기본 빌드는 Prior 3D를 비활성화한다. 실제 3D 시험 전 운영자가 공식 VWorld WebGL 3D API용 키 종류와 등록 가능한 HTTPS 도메인 및 이용 조건을 VWorld에 확인하고, 본인이 관리하는 HTTPS 시험 페이지를 준비해야 한다. 기존 실험은 선택 경도·위도·반경을 페이지에 전달하지만 실제 3D 모델, 각 위치의 제공 범위와 앱 명령 차단이 검증되지 않았다. 해당 페이지의 원격 콘텐츠 권한 격리 및 키 노출 범위를 Linux와 Windows에서 각각 확인한 후에만 실험을 진행한다. 건물 외곽선과 점군은 사전 3D 모델의 대체 증거가 아니다. 기존 분석: `stage18-prior-3d-map-report.md`.
