# 수동 입력 (설계 중)

기존 `manualInput.ts`는 WASD/방향키·반대 입력 상쇄·키 해제·Space 초기화·Escape·2초 유지 시간 초과를 지원하는 입력 미리보기다. `ManualPreview.tsx`는 blur, visibility, 텍스트 입력 포커스에서 종료하고 메뉴 전환 시 컴포넌트가 해제된다. 이 기능은 실제 기체 제어가 아니다. 입력 미리보기와 향후 개발용 가상 실행기 사이에 안전한 별도 권한 및 세션 무효화 경계가 필요하며, 기존 UI 이벤트만으로는 이를 보장하지 않는다. 실제 키보드 하드웨어 시험, 최소화 GUI 및 재생 잠금은 후속 검증이다.
