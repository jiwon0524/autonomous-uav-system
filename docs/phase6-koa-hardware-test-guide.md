# KOA FC 읽기 전용 연결 시험 계획

실제 시험은 아직 NOT TESTED다. 프로펠러를 제거하고 기체를 안전하게 고정하며 모터 구동·비행을 하지 않는다. FireScene의 ARM/DISARM·이륙·착륙·모터 및 실제 비행 명령은 잠겨 있다.

1. Windows 장치 관리자에서 USB 장치와 COM 번호를 확인한다.
2. FireScene 시스템 설정에서 자동 탐색을 확인하고, 필요하면 해당 포트를 수동 선택한다. 기존 115200 설정과 실제 FC 설정을 대조한다.
3. 포트 열기·설정 단계, RX 바이트, 유효 MAVLink 프레임, HEARTBEAT 및 기체 식별 정보를 차례로 확인한다. HEARTBEAT 대기는 연결 성공이 아니다.
4. 실제 텔레메트리를 관찰하고 진단 정보 복사 기능으로 결과를 기록한다. 민감한 장치 정보는 공유 전 확인한다.
5. 연결 해제와 안전한 재연결을 시험한다. HEARTBEAT를 받지 못하면 QGroundControl을 별도로 실행해 비교할 수 있다. 두 프로그램이 같은 직렬 포트를 동시에 점유하지 않도록 하나를 종료한 후 다른 프로그램을 실행한다.

QGroundControl은 필수 의존성이 아니다. 네트워크 격리 환경을 확보하지 못한 PX4 SITL은 NOT TESTED로 유지한다.
