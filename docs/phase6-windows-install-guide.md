# Windows 시험 후보 확인 절차

이 문서는 검증 계획이며 실제 Windows 설치 성공 기록이 아니다. 테스트 아티팩트와 SHA256을 받은 뒤 파일 이름·크기·체크섬과 출처를 확인한다. 서명되지 않은 시험 빌드는 게시자 확인 또는 SmartScreen 안내가 나타날 수 있다. 보안 기능을 해제하지 않는다.

1. 기존 Preview 1의 버전과 사용자 설정·지도 키·임무·기록을 확인하고 백업한다. 후보 내부 버전은 0.1.1이며 기존 Preview 1의 0.1.0보다 높다. 실제 업데이트 및 보존은 이 시험으로 확인한다.
2. 한국어와 영어에서 Welcome, 기존 버전 선택, 설치 경로, 시작 메뉴, 실제 진행·오류·취소, 완료 및 바탕화면 바로가기를 확인한다. WebView2가 없을 때 기존 정책은 인터넷 부트스트래퍼를 사용한다.
3. 100/125/150% 배율과 사용 가능한 해상도에서 글자·버튼 겹침을 확인한다. 앱을 실행해 스플래시, 온보딩 완료 상태, Dark/Day, 9메뉴, 크기 조절과 전체 화면을 확인한다.
4. 지도 검색, 임무, 오프라인 입력 연습, 기록·재생과 기존 데이터 보존을 확인한다. 실제 비행 명령은 잠겨 있어야 한다.
5. 제거 시 데이터 삭제 선택이 기본으로 선택되지 않았는지, 취소·오류 처리 및 제거 완료를 확인한다. 실제 삭제 시험 전 백업을 검증한다.

Windows 네이티브 컴파일 성공과 설치·업데이트·디자인 검증은 별개의 결과로 기록한다. 실기체 연결은 별도 `phase6-koa-hardware-test-guide.md`를 사용한다.
