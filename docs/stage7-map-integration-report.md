# Stage 7 지도 통합 중간 보고

상태: **미완료**. 이 변경은 지도 기반의 일부이며 현장 관제에 사용할 수 있는 완성 기능이 아니다. 기준 커밋 `71aa5f7`, 브랜치 `dev/firescene-gcs`, 디자인 태그 `design-v1.0`. 커밋 정보는 `git log -1` 참조.

## 기술 및 근거

2D에는 OpenLayers를 선택했다. 로컬 번들 엔진으로 WMTS 타일, 이동, 축척 및 좌표 변환을 제공하고 원격 스크립트를 실행하지 않는다. VWorld 공식 SDK는 서비스 고유 3D와 통합할 수 있으나 SDK 실행과 Tauri 권한 경계 및 도메인 인증을 확인해야 한다. MapLibre GL JS는 벡터 타일과 WebGL에 적합하지만 VWorld 건물·3D 데이터 호환성은 확인하지 못했다. CesiumJS는 지형·3D Tiles와 향후 점군 시각화 후보이나 VWorld 3D 데이터 형식과 접근 권한을 확인하지 못했다. WebKitGTK/WebView2 호환성, 실제 GPU·메모리·속도와 설치 용량은 네 엔진 모두 대상 환경 실측 전 미확인이다. 3D 엔진은 선택하거나 설치하지 않았다.

참고: [OpenLayers](https://openlayers.org/), [CesiumJS](https://cesium.com/learn/cesiumjs-learn/), [Tauri 보안 권한](https://tauri.app/security/capabilities/), [VWorld](https://www.vworld.kr/). VWorld 공식 개발 문서가 조사 시 응답하지 않아 최신 API 버전, 이용 조건, API별 인증, 도메인 등록 및 캐싱 허용 범위를 확인하지 못했다. WMTS 1.0.0 형식은 참고 자료에 근거한 미검증 구현이며 서비스 지원이나 인증 성공을 보증하지 않는다. 검색·데이터·3D API의 현재 명세도 확인이 필요하다.

## 현재 구현

`MapView.tsx`는 OpenLayers의 지도 인스턴스를 화면 진입 시 생성하고 종료 시 해제한다. 기본/위성 타일, 이동·확대/축소, 축척, 중심 좌표, 초기화, 크기 변경 대응, 타일 상태와 제공자 표기를 구현했다. 타일 오류는 인증과 네트워크를 구분하지 못한다. 레이어 전환 시 지도가 초기 중심으로 돌아간다. 지도 서버는 이미지로만 접근하며 원격 스크립트나 원격 Tauri capability를 추가하지 않았다. 지도는 인터넷이 필요하고 별도의 데이터 캐시는 구현하지 않았다.

시스템 설정에서 VWorld 키 및 초기 중심을 입력한다. VWorld 홈페이지에서 회원 가입 및 API 키를 신청하고 사용 API와 도메인 등록 조건을 확인한 후 입력한다. Tauri Linux의 `tauri://localhost`, Windows의 `http://tauri.localhost`가 서비스 등록에 허용되는지는 확인되지 않았다. 로컬 웹뷰 저장소는 암호화된 비밀 저장소가 아니고 키는 타일 요청 URL에도 포함된다. 인증 성공은 가정하지 않는다.

Stage 5의 GPS_RAW_INT 원시 위치가 LIVE이고 동일 송신자·시각일 때 원시 위치로 지도 이동 및 추적을 제공한다. 추정 위치로 표시하지 않는다. 위치 마커, 이동 경로, 마지막 위치, 고도·방향 표시 표시는 미구현이다. 초기 중심은 기체 위치가 아니다. 기존 안전 감시 및 기체 명령 정책을 변경하지 않았다.

## 미구현 및 검증 필요

주소·장소 검색, 검색 오류 분류와 요청 관리, 실제 건물 선택·윤곽·속성, 현장 범위, 거리 계산, 3D 모델·지형 및 카메라 조작, 2D/3D 전환, 실시간 점군 계층은 구현되지 않았다. VWorld 사전 지도는 현장 실시간 상태나 실내 정보를 제공한다고 가정하지 않는다. Stage 8에 앞서 이 항목, API 조건·권한 경계·실기기 검증을 완료해야 한다. 임무 계획은 이후 별도 단계이며 실제 비행 제어는 범위 밖이다.

실제 키가 없어 타일 로딩, 인증 오류, 기본/위성 데이터 및 실제 Tauri GUI는 검증하지 못했다. 인터넷 중단, 창 크기, GPS 및 시뮬레이션 위치, 지도 오류와 안전 감시의 상호 독립성도 GUI에서 미검증이다. 브라우저 실제 지도와 Windows WebView2 검증도 미수행이다. 프론트엔드 TypeScript 검사와 빌드 성공, Rust 테스트 19개 통과. 이전 DEB는 약 3.1 MiB였으며 실행 속도·메모리·CPU·GPU 실측은 미수행이다. Tauri 릴리스 DEB 빌드는 성공했으며 결과는 3.08 MiB다. 이전 파일은 `du -h`로 약 3.1 MiB만 확인하여 정확한 차이는 산출할 수 없다.
