# Global View 실험 — 미완료

MapLibre 공식 자료는 지구본 투영을 지원한다고 설명하지만 이 프로젝트에서 구현·성능·WebView 호환성은 검증하지 않았다. CesiumJS와 Three.js를 추가하지 않았다. 공급 데이터, 지구본 로딩과 메모리, 오류 격리 및 Tactical 전환 검증이 필요하다.

독립 `experiments/maplibre-globe/` 프로토타입은 합성 좌표만 포함하고 실제 지구 지형·해안선이 없다. 헤드리스 소프트웨어 WebGL에서 캔버스 생성은 관찰했으나 load 완료를 확인하지 못했다. 실패 시 시간 초과를 표시한다. Tactical 전환, 데이터 공급 및 실제 WebView 성능은 미구현·미검증이다.

2026-11-26 실제 타일을 사용하는 격리 Chrome SwiftShader 실험에서 Globe 전환 후 idle 및 대륙·해양·대한민국 표기가 관찰됐다. 증거: `~/FireScene-evidence/phase3/openfreemap-globe-realtime.png`. 브라우저 실험일 뿐 Tauri 모드 전환, 저장 임무·실기체 표시 또는 생산 기능은 아니다. 실제 기체 마커를 임의로 표시하지 않았다.

## Tauri 개발 전용 실험

메인 관제 지도를 계속 유지한 채 개발 전용 Global 오버레이를 열고 임무 중심·외곽선·반경 및 최신 기체 좌표를 전달하도록 구성했다. 외부 지도 타일은 OpenFreeMap이며 기체가 없으면 기체 마커를 만들지 않는다. 평면/지구본과 기본 지도 복귀 버튼은 지도 카메라만 변경한다. 실제 WebKitGTK에서 지구본, 평면 및 복귀 시나리오가 통과했다. 지도 타일 안정화 전 흰 영역이 나타난 적이 있어 로딩 품질 검증이 더 필요하다. 저장된 임무 전환·기체 방향·궤적·위성 전환과 오류 주입은 전체 시나리오로 검증되지 않았다.
