# Stage 13 공간 매핑 통합 보고

기준: Stage 12 `a9e5e07`, `dev/firescene-gcs`, `design-v1.0`, `alpha-v0.1.0`. 로컬 커밋은 이 문서를 포함하는 `git log -1`로 확인한다. 원격 push와 실제 비행 명령·자율비행·SLAM 구현은 하지 않았다.

## 구현 및 범위

길이 프레이밍 TCP의 XYZ float32/RGB8 바이너리 스냅샷 채널을 상태·영상·FC와 독립적으로 추가했다. 헤더·길이·버전·ID·시각·점 개수·유한 좌표·속도와 같은 세션의 프레임/리비전 증가를 검증한다. 세션이나 맵이 달라지면 최신 스냅샷으로 교체한다. 100,000점(최대 1.5 MB) 제한은 성능 실측 결과가 아닌 초기 자원 상한이며, WebGL에는 최대 50,000점을 균등 간격 샘플링한다. 백엔드는 최신 패킷 하나를 보관하고, 수신·IPC·프론트엔드·GPU에서 일시적으로 각각 복사본이 존재할 수 있다. GPU 버퍼는 고정 크기 재사용이며 화면 종료 시 해제한다. 전체 메모리 사용량·GPU 부하·FPS는 측정하지 않았다.

직접 WebGL 점군/색상, 3m RGB 좌표축, 회전·이동·확대 및 상단/정면/측면·초기 시점 버튼을 구현했다. 화면에서 좌표계·단위·임무 주장을 표시하나 출처는 미인증이다. 원점·방향을 모르는 좌표는 자동 변환하지 않는다. 좌표계 변환은 별도 테스트한 NED→ENU 및 단위 quaternion 기초 함수만 있으며 실제 화면 또는 WGS84 정합에는 사용하지 않는다. 카메라 위치·방향·경로·관측 영역, 기체 위치와 카메라-기체 보정의 수신·시각화는 **미구현**이다.

Prior는 기존 VWorld 실험 구조 안내이며 실제 3D 렌더링은 미검증이다. Live는 독립 점군이다. Combined는 사전 지도·점군·좌표 변환·기준·정합 정확성의 검증이 없어 비활성이다. Depth 원본의 형식·단위·intrinsics는 기존 규격에만 남으며 수신·검증·거리 표시를 구현하지 않았다. 임무 ID는 송신자의 주장으로 표시할 뿐 임무 관리와 연결·검증·저장하지 않는다. PLY/PCD 파일 불러오기·저장과 증분 갱신도 미구현이며 임의 파일 경로 권한을 추가하지 않았다.

방식·렌더러 비교, 이진 레코드, 좌표계, 팀원 계약과 개발 서버는 [공간 매핑 규격](spatial-mapping-interface-spec.md)을 따른다. 평문·미인증이므로 신뢰 가능한 격리 시험망에서만 사용한다. 운영 전 상호 인증·암호화·재생 방지 및 자원 공격 저항 검증이 필요하다. 점군은 비행 제어 및 안전 판정으로 연결되지 않는다.

## 검증과 산출물

- 프론트엔드 8개 테스트 파일, 좌표 기초 수학, TypeScript와 Vite 빌드 통과. 기존 500 kB 초과 메인 청크 경고가 남는다.
- Rust 기본 44개, simulation 45개 및 각 Tauri 권한 구성 검사 1개 통과. 합성 성능 시험은 각 1개 제외했다. 로컬 TCP에서 점군 패킷 수신·세션 교체를 확인했고 길이·NaN·최대 개수·미지원 증분을 거부하는 단위 검사를 통과했다. 루프백 검사는 승인된 환경에서 실행했다.
- GUI 렌더링·GPU 버퍼 생명주기·장시간 과부하·데이터 중단/과속의 전체 UI 경로, FC 안전 감시 동시 동작, 실제 Pi·RGB-D·SLAM·거리·Windows 빌드 및 VWorld 3D는 **PENDING**이다. Depth 수신 미구현이므로 실제 Depth 검증도 수행하지 않았다.
- Ubuntu 24.04 amd64 Tauri 릴리스 및 DEB 생성 성공. `src-tauri/target/release/bundle/deb/FireScene GCS_0.1.0_amd64.deb`는 **5,693,670 bytes**, Stage 12의 5,672,358 bytes 대비 **21,312 bytes 증가**. 실행 파일 18,655,456 bytes; frontend/dist 689,205 bytes. DEB 목록에 개발 서버는 없다. 설치·실행은 미검증이다.

## 사용자 확인 및 다음 단계

Ubuntu GUI에서 별도 터미널에 `python3 tools/spatial_fixture.py`를 실행하고 3D 매핑 → Live Mapping에 `127.0.0.1:8767`을 입력한다. 개발용 합성 점군의 색·시점·축·확대·이동·메뉴 전환과 정리를 확인한다. `--case session`, `invalid`, `length`, `flood`, `stop`은 독립 실행으로 확인한다. 팀과 축·원점·자세·임무 및 보안 계약을 합의하고 실기기에서 검증한 뒤 Depth, 자세·경로·관측 영역, 안전한 파일 교환, 증분 및 근거 있는 정합을 별도 개발한다.
