# Tactical Map — 진행 기록

OpenLayers/VWorld 기본·위성 지도와 기존 축척, 출처, 건물 외곽선, 범위, 500점 이내 GPS 궤적을 유지한다. 확대·축소, 북쪽 복원, 현장 이동을 추가했다. 유효한 동일 시스템·컴포넌트의 최신 heading이 있으면 방향 삼각형, 없으면 원형 위치 마커로 표시한다. 기체 또는 현장으로 화면을 이동하는 동작은 지도 카메라만 변경한다. GPS 추적 중 사용자가 지도를 드래그하면 추적을 끈다. 타일은 래스터이므로 테마 적용을 위해 지도 자체의 가독성을 훼손하는 필터를 적용하지 않았다. 실제 기체·지도 인증 및 방향의 시각 검증은 미완료다.
