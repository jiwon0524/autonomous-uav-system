이번 회귀의 생산 코드와 `9852fbd` 사이의 변경은 없다. 미커밋 Rust 변경은 테스트, 예제 변경은 개발용 합성 생성기, Python 변경은 GUI 시험이다. 앞 절에서 복구한 결과는 각각의 당시 테스트 실행 기록이며 실행 당시 작업 트리 전체가 남지 않아 현재 코드의 재실행 결과로 취급하지 않는다. 연결 경합의 복구된 GUI 결과는 `9852fbd` 직전 생성됐으므로 최종 코드의 증명으로 간주하지 않는다. 별도의 [최종 경합 재시험](evidence/phase4-resume/closure-race.json)은 오래된 상태·해제 오류·연결 중 해제를 개발용 호출 지연으로 검사해 PASS했다. 직렬·부분 데이터 결과는 `700e38a` 이후 생성됐지만 정확한 당시 전체 스냅샷은 불명이다. 복구 기록의 기록 시험은 연결 이벤트 및 세션 분리이고 재생은 이번 전체 GUI 시험에서 별도 통과했다.

현재 세션: TypeScript PASS, 프런트엔드 17개 테스트 파일 PASS, 생산 빌드 PASS (최대 JS 667.34 kB, 500 kB 경고). Rust 기본 56개 및 simulation 57개 PASS, 각각 benchmark 1개 ignored, Tauri 권한 테스트 각각 1개 PASS. 이후 테스트 전용으로 추가한 HEARTBEAT·착륙·NED 시험은 기본 및 simulation에서 각각 별도 PASS. 최초 샌드박스 Rust 전체 실행은 로컬 소켓 EPERM으로 기본 7개·simulation 8개 실패했고, 허용된 환경에서 위와 같이 전체 재실행했다.
