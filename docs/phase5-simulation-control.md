# 가상 제어 및 SITL (설계 중)

기존 simulation feature의 합성 UDP 수신은 텔레메트리 테스트이며 조종 실행기가 아니다. `src-tauri/src/virtual_control.rs`는 simulation과 debug assertions가 모두 활성인 빌드에서만 컴파일되는 메모리 전용 모델이다. 네트워크와 연결 관리자를 참조하지 않으며 IPC에 노출하지 않았다. 입력을 [-1,1]로 제한하고 시간 초과 500ms, 역행 시각, 비유한 값, 권한 상실 시 입력을 무효화한다. 한 번의 상태 갱신은 최대 100ms로 제한한다. 세션 변경 시 상태가 초기화된다. 이는 동역학 모델이나 PX4 SITL이 아니고 아직 화면·입력·기록에 연결되지 않았다. 가상 실행기는 실기체 데이터·기록 재생·실제 통신과 독립해야 하고 생산 패키지에서 제외되어야 한다. 주소나 포트 번호만으로 SITL을 신뢰하지 않는다. 가상 위치와 자세는 합성 출처를 표시하며 입력 해제·권한 상실·시간 초과·종료 시 입력을 무효화해야 한다.

환경 읽기 전용 조사에서 PX4 SITL 실행 파일과 `gz` 명령은 존재한다. 실제 네트워크와 분리할 `unshare --net true` 사전 점검은 샌드박스 안과 권한 상승 실행 모두 Operation not permitted로 실패했다. 따라서 실제 PX4 SITL/Gazebo 실행은 하지 않았으며 파일 존재가 정상 동작을 뜻하지 않는다. SITL 제어 경로는 구현하지 않았고 실제 직렬·일반 UDP로 제어 메시지를 송신하지 않는다.

입력 모델에는 세션별 단조 증가 순번을 추가하여 늦거나 중복된 요청이 이후 중립 입력을 덮지 않도록 단위 시험했다. 마지막 입력 이후 500ms가 지난 입력은 상태 폴링 없이도 잠금을 유발한다. 현재 IPC는 없고 요청 생성 시점의 신뢰 가능한 검증·권한 전이·재생과의 통합은 미완료다.

## 2026-11-26 구현 및 검증 현황

위 IPC 미노출 설명은 초기 상태다. 현재 개발 simulation IPC는 메모리 전용이며 500ms 입력 임대와 독립 50ms 감시, 연결·재생 상호 배제 및 유한 비차단 이벤트 큐를 사용한다. 5가지 위험 주입 전 활성 입력과 이후 중립·이전 토큰 거부를 실제 Tauri에서 확인했다. release 실제 IPC 거부 및 안전하게 격리된 SITL은 아직 검증하지 않았다.
