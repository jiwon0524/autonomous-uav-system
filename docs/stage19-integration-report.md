## 사용자 흐름과 수정

설정에서 직접 직렬 또는 QGC/Router 로컬 전달을 선택하고 기체·안전 상태를 확인한다. 2D에서 주소·건물을 선택해 임무를 생성/저장하고, 종합 관제에서 선택 임무와 대상·지도·텔레메트리를 확인한다. 최신 연결에서는 키보드 입력을 PREVIEW로만 확인한다. 기록 화면에서 임무를 확인해 기록을 시작·종료하고 REPLAY를 실시간 안전 감시와 분리해 확인한다.

기존 종합 관제는 임무 선택과 무관하게 항상 임무가 없다고 표시했다. 임무 화면에서 편집한 미저장 위치가 공유 지도에 반영될 수도 있었고, 화면을 다시 열면 선택된 임무가 편집기에서 사라졌다. 이제 저장소에서 선택·저장한 임무의 이름·상태·대상을 세션 동안 공유하고, 다시 임무 화면을 열면 저장된 항목을 불러온다. 새 현장 선택이나 반경 변경으로 저장된 임무 위치와 달라지면 선택 임무를 해제해 잘못된 연관 표시를 피한다. 임무 편집 중 지도 변경은 저장 성공 전 공유하지 않는다. 새 임무 생성도 이전 임무 선택을 해제한다. 앱 재시작 후 선택은 자동 복원하지 않으며 임무 목록에서 다시 선택한다.

기록 화면은 진입 시 선택된 임무를 기본 제안하지만 사용자가 변경하거나 연결하지 않을 수 있다. 기록 헤더의 임무 ID는 **기록 시작 시 고정**되며, 이후 임무 선택·변경·삭제는 기존 기록을 변경하거나 삭제하지 않는다. 실시간 임무의 이름·좌표 스냅샷은 기록하지 않고 ID만 보관하므로 임무가 삭제되면 이름이나 당시 위치를 복구할 수 없다. 기록 중 임무를 바꿔도 기록 세션은 계속되며 새 임무로 자동 전환되지 않는다. 목록에서 찾지 못한 ID는 기록 상세에 그대로 표시한다. 실제 GUI 상호작용은 PENDING이다.

연결 상태 조회가 멈추면 이전 CONNECTED가 계속 남을 수 있어 1.5초 제한과 UNKNOWN 표시를 추가했다. 조회 성공 후 정상 폴링으로 복구하며 타임아웃된 늦은 응답은 상태를 되살리지 않는다. 기존 통신·안전 상태 저장소는 변경하지 않았다. 상단의 연결 중·손실·오류를 일괄 미연결로 숨기지 않고 구분한다. 기록 상태 조회 실패는 기록 중 아님이 아닌 확인 불가로 표시하고 재조회 전 시작을 차단한다. 조회가 가능하지만 이전 저장 오류가 남은 경우에는 재시도를 허용한다. 임무 저장 중 중복 선택·편집을 제한하고, 저장 중 화면 이탈 시 임무 선택을 해제하며 늦은 완료 응답이 다른 현장 상태를 덮지 않도록 했다.

## 안전·성능 범위

QGC 경로는 사용자 선택값이며 송신자 인증이 아니다. Companion·카메라·점군 및 QGC 로컬 전달은 평문/미인증이고 신뢰 가능한 격리 시험망에서만 사용한다. 운영 전 인증·암호화·재생 방지와 자원 공격 검증이 필요하다. 비행 명령 잠금, 외부 WebView 권한 구성, 키보드 PREVIEW 및 REPLAY 분리는 유지한다. 실제 명령 송신 기능은 추가하지 않았다. 개발 simulation handler는 기본 feature에서 제외된다. VWorld 3D는 기존 도메인·격리·GUI 검증 전까지 비활성이다.

지도·영상·점군 및 기록의 기존 unmount 정리와 공유 폴링 구조를 검토했고 새 폴링 타이머를 추가하지 않았다. 임무·기록 화면의 비동기 결과가 화면 종료 뒤 UI 상태를 바꾸지 않도록 기존 가드와 신규 임무 저장 가드를 사용한다. 프로세스·GPU 메모리와 실제 장시간 사용은 측정하지 않았으므로 성능 향상을 주장하지 않는다. 외부 3D 창은 별도로 닫아야 하는 Stage 18의 제한이 남는다.

## 검증

- 프론트엔드 12개 테스트 파일 통과: 임무/현장 동일성·삭제된 선택, 연결 조회 시간 제한·오류, 기존 재생·키보드·지도·안전 및 기타 회귀. 선택 상태의 실제 메뉴·DOM 전환이나 외부 장치 오류 통합 GUI 시험은 포함하지 않는다.
- Rust 기본 47개, simulation 48개 및 각 Tauri capability 구성 검사 1개 통과. 합성 성능 시험 각 1개 제외. 기록 헤더의 임무 ID와 별도 임무 파일 제거 후 기록 보존을 테스트했다. 루프백은 승인된 환경에서 실행했다.
- TypeScript·Vite 빌드와 Ubuntu 24.04 amd64 Tauri 릴리스 DEB 생성 통과. `src-tauri/target/release/bundle/deb/FireScene GCS_0.1.0_amd64.deb` **5,710,474 bytes**, Stage 18의 5,710,340 bytes 대비 **134 bytes 증가**. 실행 파일 18,698,720 bytes; frontend/dist 702,056 bytes. Vite 500 kB 메인 청크 경고가 남는다.
- 기본 feature에서 개발 telemetry_feed 빌드가 feature 요구로 거부되고 프론트엔드 산출물과 릴리스 심볼에서 simulation 연결 구현을 찾지 못했다. capability는 main 전용의 정적 검사만 통과했으며 원격 WebView 실제 IPC 거부는 미검증이다. 배포 파일 목록에 개발 시험 도구는 없다.
